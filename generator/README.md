# libsim — симулятор онлайн-бібліотеки

Генератор датасетів формату v2 для СППР. Бібліотека симулюється день за днем із **закладеними залежностями** (відтік, ефект дій, смаки, дефіцит ліцензій). Окремо пишеться `ground_truth.json`, за яким експериментальний розділ магістерської вимірює якість рішень системи.

Статус: каркас пакета (M0). Симуляцію реалізуємо в M1, див. план v2.

```bash
uv run libsim --help
uv run pytest generator
```

Каталог книг з бакалаврської (`book_database.json`) свідомо не використовуємо:

- жанри в ньому визначені пошуковим запитом;
- кількість сторінок випадкова;
- ISBN порожні;
- є назви російською.

Каталог для v2 будуємо заново в M1. **Жодного російськомовного контенту**.
